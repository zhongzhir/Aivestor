# 项目分析

## 工作流程

1. **新建项目** — 填写项目名称和基本信息
2. **上传文件** — 支持 BP（PDF/Word/PPT/Excel），单次最多 20 个文件，单文件最大 25MB
3. **填写判断** — 记录你的看多理由、看空理由、创始人评估和核心假设
4. **生成报告** — AI 结合你的判断和知识库生成七章节深度分析报告

## 报告结构

标准报告包含七个章节：
1. 执行摘要
2. 市场与赛道分析
3. 产品与商业模式
4. 团队评估
5. 财务分析（自动提取上传文件中的财务数据）
6. 风险与挑战
7. 投资判断综合

## 简要分析

如果还没有完整的投资判断，可以先使用「**简要分析**」快速入库：无需填写三条判断，直接基于 BP 生成轻量版分析，适合项目初筛阶段。

## 报告导出

支持导出为：
- **Word（.docx）**：适合修改和打印
- **PPT（.pptx）**：适合投委会演示
