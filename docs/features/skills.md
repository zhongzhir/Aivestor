# SKILL 广场

SKILL 是可复用的投资分析框架模板。[无需登录即可浏览全部官方框架 →](https://aivestor.cn/skills)

## 使用方式

**基础用法：** 在项目分析页上传 BP 后，选择一个 SKILL，AI 会按照该框架生成专项分析。

**进阶用法：** 创建自己的 SKILL，把你常用的分析问题清单和评估框架写成模板，下次看类似项目直接调用。

## 官方框架示例

- **魔鬼代言人** — 对投资假设发起系统性挑战
- **消费赛道分析** — 品牌/渠道/复购/竞争壁垒四维评估
- **创始人评估框架** — 能力、动机、团队化三维判断
- **财务健康扫描** — 关键指标提取与异常识别
- ……共 20+ 框架

## 自建 SKILL

将你的分析方法论固化为可复用模板：

1. 进入「SKILL 广场」→「创建 SKILL」
2. 填写框架名称、适用场景、分析维度
3. 保存后在项目分析页即可选用

这是把你的方法论变成资产的核心路径。
