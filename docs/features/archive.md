# 项目档案

项目档案用于跨项目检索历史记录；单个项目的日常推进则在 2.0 项目工作区中完成。项目工作区把材料、分析、投资决策、关系上下文、项目时间线与投后管理放在同一处，从初次接触一直延续到退出。

## 核心字段

| 字段 | 说明 |
|------|------|
| 融资阶段 | 天使 / Pre-A / A / B / C…… |
| 跟进阶段 | 初步了解 / 深度尽调 / 投委会 / 已投 / 已过 |
| 投资结果 | 待定 / 已投 / 已过 / 盈利退出 / 亏损退出 |
| 判断记录 | 每个阶段的看多/看空/创始人评估 |
| 文件归档 | 所有上传的 BP 和相关文件 |
| 分析报告 | 所有生成的分析报告（含简要分析） |
| 工作流信息 | 下一步动作、负责人、截止日期、证据完整度与最近有效活动 |
| 投资节点 | 立项、尽调、投委会、交割、Pass 等节点事件与结论 |
| 关系上下文 | 相关人员、机构、介绍来源、角色和关系强度 |
| 投后管理 | 投后材料、结构化指标、行动项、退出策略与投后报告 |

## 筛选与检索

支持多维度筛选：
- 按融资阶段、跟进阶段、投资结果筛选
- 关键词搜索（项目名称 + 判断内容）
- 按创建时间 / 更新时间排序

## 为什么要记录结果

项目档案中的投资结果（outcome）和项目内的判断、节点、指标与退出记录共同构成长期回溯基础。它们让投前假设能够在投后被验证，也为识别判断偏差和复用历史经验保留可追溯依据。
