# 项目档案

项目档案记录每个项目的完整生命周期，从初次接触到最终结果。

## 核心字段

| 字段 | 说明 |
|------|------|
| 融资阶段 | 天使 / Pre-A / A / B / C…… |
| 跟进阶段 | 初步了解 / 深度尽调 / 投委会 / 已投 / 已过 |
| 投资结果 | 待定 / 已投 / 已过 / 盈利退出 / 亏损退出 |
| 判断记录 | 每个阶段的看多/看空/创始人评估 |
| 文件归档 | 所有上传的 BP 和相关文件 |
| 分析报告 | 所有生成的分析报告（含简要分析） |

## 筛选与检索

支持多维度筛选：
- 按融资阶段、跟进阶段、投资结果筛选
- 关键词搜索（项目名称 + 判断内容）
- 按创建时间 / 更新时间排序

## 为什么要记录结果

项目档案中的投资结果（outcome）是 Aivestor 长期演进的数据基础。未来版本将支持：回溯哪些判断因素与最终结果正相关，帮助你识别自己的判断盲区。
