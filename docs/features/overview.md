# 功能概览

Aivestor 围绕投资工作流提供六大核心模块：

| 模块 | 路由 | 核心功能 |
|------|------|---------|
| 首页仪表盘 | /dashboard | 项目总览、知识库状态、近期活动 |
| AI 对话 | /chat | 与 AI 自由探讨，可关联具体项目 |
| 项目分析 | /projects | 上传 BP，生成深度分析报告 |
| 项目档案 | /archive | 项目全生命周期记录与检索 |
| 私有知识库 | /knowledge | 知识沉淀、向量检索、手动管理 |
| SKILL 广场 | /skills | 投资分析框架库，支持自建 |

详细说明见各功能页面。
