# 私有知识库

## 核心价值

私有知识库是 Aivestor 区别于所有通用 AI 工具的核心能力。你在这里积累的每一条判断，都会在你分析新项目时被自动调用。

## 知识来源

知识库内容通过多种方式自动沉淀：

- **报告沉淀**：每次生成分析报告后，系统自动提炼关键洞察
- **对话摘要**：AI 对话中的重要内容会被提炼为知识条目
- **文档拆块**：上传的 BP 文件被拆分为向量索引块，供检索调用
- **手动添加**：你可以随时手动添加任何想保存的内容

## 检索机制

分析新项目时，系统通过**向量语义检索**自动召回相关历史记录：

- 相似行业的历史项目判断
- 相关赛道的认知积累
- 类似创始人背景的经验

这些内容作为上下文提供给 AI，让分析更个性化、更有参照价值。

## 隐私保障

你的知识库数据：
- 与其他用户完全隔离，存储在你的私有空间
- Aivestor 团队在技术层面无法随意访问
- 支持 Docker 本地部署，数据完全不出内网
