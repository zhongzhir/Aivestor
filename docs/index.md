## 使用方式

普通用户无需下载安装，访问 [aivestor.cn](https://aivestor.cn) 注册即可使用；需要桌面入口时，可在 Chrome 或 Edge 中选择「安装 Aivestor」。

如果你需要把项目材料、数据库和上传文件保留在自己的电脑、服务器或机构内网，可使用 Docker 私有化部署。详见 [私有化部署指南](/deploy/docker)。
