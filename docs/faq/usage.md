# 常见问题 — 使用问题

## 为什么报告生成这么慢？

AI 生成七章节深度分析报告通常需要 **1-3 分钟**。报告采用流式输出，内容生成过程中实时显示，不需要等到全部完成再看。

如果超过 5 分钟仍未完成，可能是 API 平台响应较慢，可以尝试刷新重试，或切换到 DeepSeek（响应速度最快）。

## SKILL 怎么用？有什么好的方式？

**基础用法：** 在项目分析页上传 BP 后，选择一个 SKILL，AI 会按照该框架生成专项分析。

**进阶用法：** 创建自己的 SKILL，把你常用的分析问题清单写成模板，下次看类似项目直接调用。

这是把你的方法论固化成工具的核心路径。详见 [SKILL 广场说明](/features/skills)。

## 知识库的内容怎么被调用到？

通过**向量语义检索**自动调用。当你分析新项目时，系统会自动检索知识库中与当前项目相关的历史记录（相似行业、相似赛道、相似创始人背景），并作为上下文提供给 AI。

## AI 不记得我之前说的话怎么办？

请确认你在「对话」模块使用的是同一个对话会话（左侧对话列表中选择对应会话）。每个会话内是有上下文记忆的。

跨会话的持久记忆通过「个人设置」中的用户画像和知识库实现。设置了用户画像后，AI 在每次对话中都会读取这些偏好设置。
