# 常见问题 — 数据与安全

## 我上传的 BP 和项目信息会被泄露吗？

Aivestor 会按产品功能存储和处理你的项目材料、对话与工作记录，并通过用户、组织和项目权限隔离不同账号的数据。平台不会把你的材料公开给其他用户，也不会把你的 API Key 明文保存或写入日志。

关于 AI 分析时的数据流：分析时您的文档内容会通过您配置的 API Key 发送给对应的 AI 平台（DeepSeek/OpenAI 等），这个过程和您直接使用那些平台没有本质区别。

如果对数据出境、内网访问或机构合规有严格要求，建议使用 [Docker 私有化部署](/deploy/docker) 版本，把数据库、上传文件和项目记录保留在自控环境。

## API Key 如何安全存储？

所有 API Key 使用 **AES-256-GCM** 加密后存储，加密 IV 每次随机生成并拼接存储，即使数据库文件被获取也无法反推原始密钥。密钥只在您使用 AI 功能时在服务端临时解密调用，不会明文传输或记录日志。

## 有本地部署版本吗？

有，**Docker 私有化部署已可用**。

[查看 Docker 部署指南 →](/deploy/docker)

数据库、上传文件和项目记录可以保存在你的本机、服务器或机构内网环境中，适合对数据边界有严格要求的团队。
