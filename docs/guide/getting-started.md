# 快速开始

## 注册与登录

1. 访问 [aivestor.cn](https://aivestor.cn)
2. 点击「注册」，填写邮箱或手机号
3. 完成手机号绑定，获得平台代付的免费 DeepSeek 额度（500万 tokens）

## 完善个人画像

注册后建议先完成「个人设置」中的用户画像：

- 关注赛道和阶段
- 投资风格偏好
- 常用分析框架

**这是让 AI 真正懂你的第一步。** 画像越完整，分析报告越贴合你的视角。

## 创建第一个项目

1. 进入「项目分析」页面
2. 点击「新建项目」，输入项目名称
3. 上传 BP 文件（支持 PDF / Word / Excel / PPT，最大 25MB，最多 20 个）
4. 填写你的初步投资判断（看多理由 / 看空理由 / 对创始人的评估）
5. 点击「生成分析报告」

报告通常在 1-3 分钟内生成，采用流式输出，内容实时显示。

## 探索 SKILL 广场

进入「SKILL 广场」浏览 20+ 官方分析框架，无需登录即可查看。

推荐新用户先体验：
- **魔鬼代言人**：对投资假设发起挑战，识别潜在盲点
- **消费赛道分析框架**：适合消费类项目的系统评估
- **创始人评估框架**：结构化评估团队能力

## 开始沉淀知识库

每次生成报告后，系统会自动提炼关键内容到知识库。你也可以在「知识库」页面手动添加条目，比如：

- 某次投委会上的关键洞察
- 一篇对你影响深刻的研究报告
- 你对某个赛道的长期判断

这些内容在你分析新项目时会被自动调用，让每次分析都站在你的完整认知上。
