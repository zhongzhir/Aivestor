# 什么是 Aivestor

Aivestor 是专为**一级市场投资从业者**（VC / PE / CVC / 天使）设计的 AI 增强型工作台。

## 核心理念

一级股权投资是高度依赖个人判断的工作。每一次投资决策背后，都有投资人积累多年的行业认知、项目经验和方法论。但这些认知往往散落在笔记、邮件、记忆中，难以沉淀、复用和传承。

Aivestor 的核心目标：**把你的认知变成可以被 AI 持续调用的资产。**

## 四个维度形成成长飞轮

```
    当下工作（BP分析·尽调·报告）
           ↓
经验内化 →  Aivestor  ← 能力外扩
（私有知识库）  ↓  （SKILL广场）
        持续成长
   （认知演变·能力追踪）
```

- **当下工作**：快速分析 BP、生成报告、对话探讨
- **经验内化**：判断自动沉淀为私有知识库，越用越丰富
- **能力外扩**：SKILL 广场固化方法论，可复用可分享
- **持续成长**：认知演变可追踪，投资能力持续提升

## 与通用 AI 的本质区别

| | 通用 AI（ChatGPT / DeepSeek） | Aivestor |
|---|---|---|
| 记忆 | 每次对话清零 | 持续积累你的判断历史 |
| 场景 | 通用对话 | 投资专用工作流 |
| 数据 | 喂养平台模型 | 私有知识库，完全归你 |
| 框架 | 通用回答 | 调用你的 SKILL 和画像 |
